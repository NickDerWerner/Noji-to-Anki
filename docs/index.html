    2 Import into Anki

    1. Double-click the .apkg file you downloaded. Anki opens and shows an import window. (Or open Anki yourself and go to File → Import.)
    2. Click Import. That's it: your cards, sub-decks and images are now in Anki.
    Using the text file instead
    1. Unzip the download. Mac: double-click it. Windows: right-click → Extract All. You get a folder with a .txt file and an attachments folder.
    2. Import the cards. Open Anki, go to File → Import and choose the .txt file. Make sure Allow HTML in fields is checked, then click Import.
    3. Copy the images. Copy everything inside the attachments folder into Anki's media folder:
      1. In Finder, press ⌘ Cmd + ⇧ Shift + G.
      2. Paste ~/Library/Application Support/Anki2/User 1/collection.media
      3. Press Enter and paste the images there.
      1. Press Win + R.
      2. Paste %APPDATA%\Anki2\User 1\collection.media
      3. Press Enter and paste the images there.
      1. Open ~/.local/share/Anki2/User 1/collection.media
      2. Paste the images there.

      If your Anki profile isn't called “User 1”, use its name instead.

    Questions

    Is my deck uploaded anywhere?

    No. The conversion runs entirely in your browser, and your file is never sent to a server. The only thing the page loads from the internet are images that are missing from your export, and those come straight from Noji.

    I already imported this deck before. Will I get duplicates?

    No. Importing the .apkg again updates the cards that are already there instead of adding them a second time.

    Some images show up as a broken picture in Anki

    With the .apkg, images are imported automatically. If you used the text file instead, make sure you copied the files from the attachments folder of this download into collection.media. Each card points to a file like c4915ef6-….jpg, and that exact file needs to be there. Files with other names (for example 409095344.jpg) come from a different import and won't work for these cards.

    Can I use this from the command line instead?

    Yes. The same converter is available as a Python script on GitHub.
