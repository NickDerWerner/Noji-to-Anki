1 Export your deck from Noji

  1. In Noji, open the deck you want to move and go to its “Settings”.
  2. Choose “Export deck” and pick the “OFC” format. (Not CSV: CSV leaves out images.) Exporting a deck includes all its sub-decks.
  3. Turn on the option to include your learning progress. Your cards then keep their due dates and intervals in Anki instead of starting over as new cards.
  4. Enter your email address. Noji emails you a download link once the file is ready, which can take a few minutes for big decks.
  5. Download the .ofc file from the email within 24 hours. After that, Noji deletes it.

    3 Import into Anki

    1. Double-click the .apkg file you downloaded. Anki opens and shows an import window. (Or open Anki yourself and go to “File → Import”.)
    2. Turn on “Import any learning progress” in the import window if you exported your learning progress. Don't skip this: without it, all cards arrive as new, and importing again later won't fix it.
    3. Click “Import”. That's it: your cards, sub-decks and images are now in Anki.
    Using the text file instead
    1. Unzip the download. Mac: double-click it. Windows: right-click → “Extract All”. You get a folder with a .txt file and an attachments folder.
    2. Import the cards. Open Anki, go to “File → Import” and choose the .txt file. Make sure “Allow HTML in fields” is checked, then click “Import”.
    3. Copy the images. Copy everything inside the attachments folder into Anki's media folder:
      1. In Finder, press ⌘ Cmd + ⇧ Shift + G.
      2. Paste ~/Library/Application Support/Anki2/User 1/collection.media
      3. Press Enter and paste the images there.
      1. Press Win + R.
      2. Paste %APPDATA%\Anki2\User 1\collection.media
      3. Press Enter and paste the images there.
      1. Open ~/.local/share/Anki2/User 1/collection.media
      2. Paste the images there.

      If your Anki profile isn't called “User 1”, use its name instead.

    Questions

    I can't find “Export deck” in Noji, or my deck can't be exported

    Noji only lets you export decks you created yourself. Decks you imported or duplicated from someone else can't be exported. This is a limit in Noji, not in this converter. See Noji's help article on exporting.

    Is my deck uploaded anywhere?

    No. The conversion runs entirely in your browser, and your file is never sent to a server. The only thing the page loads from the internet are images that are missing from your export, and those come straight from Noji.

    I already imported this deck before. Will I get duplicates?

    No. Importing the .apkg again updates the cards that are already there instead of adding them a second time. Their learning progress in Anki stays as it is.

    Some images show up as a broken picture in Anki

    With the .apkg, images are imported automatically. If you used the text file instead, make sure you copied the files from the attachments folder of this download into collection.media. Each card points to a file like c4915ef6-….jpg, and that exact file needs to be there. Files with other names (for example 409095344.jpg) come from a different import and won't work for these cards.

    Can I use this from the command line instead?

    Yes. The same converter is available as a Python script on GitHub.

    Does my learning progress carry over from Noji?

    Yes, if you exported with learning progress. Every card keeps its state (new, learning or review), its next due date, its interval and its ease. Cards you forgot recently stay in relearning, and frozen cards become suspended cards. When the deck is ready, the converter tells you how many cards keep their progress.

    I forgot to turn on “Import any learning progress”. How do I fix it?

    In Anki, delete the deck you just imported (click the gear icon next to it, then “Delete”). Then import the .apkg again, this time with “Import any learning progress” turned on. Importing again without deleting first won't help: Anki sees that the cards already exist and leaves them as new.

    Why are so many cards due at once?

    Your cards are due on the same days as in Noji. If you haven't studied for a while, they are all overdue, just as they would be in Noji. Anki shows up to 200 reviews per day by default, so the pile gets spread over a few days. You can change this limit in the deck's options.

    Where are my frozen cards?

    Frozen cards are suspended in Anki: they keep their progress but don't show up for review. To find them, open “Browse” and search for is:suspended. Select them and press “Toggle Suspend” to study them again.

    Is my review history or streak imported?

    No. Noji's export only contains each card's current state, not the list of your past reviews, so your streak and Noji statistics can't be carried over. So that Anki's FSRS scheduler can work with your cards right away, every learned card gets one estimated review on the day you last studied it in Noji.

    Can I keep studying in Noji and move over later?

    Yes, but progress is only taken over on the first import. If you import the same deck again later, Anki updates the card contents but keeps the progress it already has. To bring over newer progress from Noji, delete the deck in Anki first, then import the new export.

    Does learning progress work with the text file download?

    No. Only the .apkg can carry learning progress. The text file always imports all cards as new.
